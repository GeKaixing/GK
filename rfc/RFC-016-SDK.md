# OSP RFC-016: SDK Specification

**Status:** Draft
**Version:** OSP Core v1.0

## Abstract

Defines the SDK requirements for interoperable OSP clients, Country servers, federation nodes, and capability providers.

## SDK Layers
- Client SDK
- Server SDK
- Federation SDK
- Identity/Passport SDK
- Capability SDK

## Required Abstractions
SDKs SHOULD expose APIs for Identity, Country, Passport, Actor, Object, Event, Repository, Federation, Customs, Recognition, Social Graph, Communication, Feed, and Capability.

## Compatibility
SDKs MUST preserve OSP object semantics and signature verification.
