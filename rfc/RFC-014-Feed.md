# OSP RFC-014: Feed Protocol

**Status:** Draft
**Version:** OSP Core v1.0

## Abstract

Defines an open Feed interface that separates social data ownership from ranking and presentation.

## Feed Providers
A Feed MAY be generated by:
- chronological logic
- community logic
- third-party algorithms
- AI ranking services

## User Choice
Actors SHOULD be able to choose or switch Feed Providers.

## Transparency
Feed Providers SHOULD declare data sources, ranking signals, moderation interactions, and applicable policies.
