# OSP RFC-013: Communication Protocol

**Status:** Draft
**Version:** OSP Core v1.0

## Abstract

Defines person-to-person, person-to-AI, AI-to-AI, group, and community communication primitives without requiring the protocol to distinguish Actor type.

## Modes
- direct messaging
- group messaging
- asynchronous messages
- real-time events
- media messages

## Security
Private communications SHOULD support end-to-end encryption, device keys, forward secrecy where available, and explicit access control.

## Federation
Cross-Country communication follows federation, recognition, Customs, and recipient policy rules.
