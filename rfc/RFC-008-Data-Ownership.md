# OSP RFC-008: Data Ownership Protocol

**Status:** Draft
**Version:** OSP Core v1.0

## Abstract

Defines user data ownership and control. Countries operate infrastructure and enforce local policy, but hosting does not imply ownership of an Actor's personal data.

## Ownership Rights
An Actor SHOULD be able to:
- access
- export
- migrate
- grant access
- revoke access
- delete where technically and legally possible

## Private Data
Private messages, private files, memory, and restricted content MUST be permission-controlled.

## Country Destruction
Country destruction, shutdown, fork, or integration MUST NOT by itself transfer or erase an Actor's ownership rights.
